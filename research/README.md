## 2. 단계별 결과 요약

### (1) 래리 윌리엄스 변동성 돌파 K=0.5 — 일봉, 코스피200 전체
- 익일 시가 청산 기준 **Gross +254%**(Sharpe 2.54)지만, **현실 비용(왕복 0.30%)에선 −60%**. 일 100% 회전이라 비용에 취약.
- 지수 단순보유(+283%)에 절대수익 열위, 위험조정만 우위. → `charts/backtest_chart.png`

### (2) 14분 오프닝레인지 돌파(ORB) + 당일청산 — 5분봉
- gross부터 마이너스(−0.12%/회). 14분은 너무 짧아 가짜 돌파 多. → `charts/intraday_chart.png`

### (3) 30분 ORB + 거래대금×변동성 상위 10종목
- 좁히니 Gross +21.8%로 전환. 단 **인샘플 선택편향**이 컸음. → `charts/intraday10_chart.png`

### (4) 워크포워드(전주 상위10 → 당주 매매) — 선택편향 제거
- Gross +7.4%(엣지 생존), 하지만 Net@0.20% −3.6%. 손익분기 왕복비용 ~0.13%. → `charts/wf_chart.png`

### (5) 숏 추가(양방향)
- 숏 단독은 강세장에서 −10%(엣지 없음). 양방향은 분산효과로 Gross +23%, Net@0.20% +10% — *숏은 수익원이 아니라 변동성 완충재*. → `charts/wfs_chart.png`

### (6) 인버스 ETF로 하방 대체
- 강세장에서 인버스는 순수 드래그(Net@0.20% −12%). 지수 자체가 장중에도 올라 인버스 ORB가 깨짐. → `charts/wfi_chart.png`

### (7) 오버나잇 vs 장중 분해 (핵심 발견)
- **코스피200 3년 수익의 95%가 오버나잇(밤사이 갭)에서 발생**, 장중은 5%. → 당일청산 전략이 지수에 지는 구조적 이유.

### (8) 한국형 단기 평균회귀 (급락주 시가매수→종가매도)
- 반전 강하게 확인: 급락주 Gross +246%(Sharpe 2.16) vs 급등주 매수(모멘텀) −92%.
- **단 비용에 죽음**(Net@0.20% −20%). 매일 굴리면 회전 과다. 엣지는 **극단 급락(≤−10%)에만** 집중. → `charts/mr_chart.png`

### (9) 신고가 돌파
- **질문형(익일 시가매수→종가매도)은 손실**(−74~90%). 신고가 종목 상승은 *장중이 아니라 밤사이*에 발생.
- **올바른 형태 = 돌파일 종가 매수 → 익일 시가 매도(오버나잇)**: 52주 신고가 Net@0.20% **+84.7%**, Sharpe 1.19. → `charts/nh_chart.png`

### (10) 상승주 페이딩(시가 공매도→종가 환매)
- 갭상승 페이딩이 하락주 반전보다 강함: +5%부터 비용 이김, +10%는 Net@0.30% +3.3%/회, 승률 69%. → `charts/fade_chart.png`

### (11) 13개 기법 통합 순위 (Net@0.20%, `scripts/battery.py`)
1. 갭상승≥+5% 시가 공매도→종가 환매: **+1670%** (Sharpe 2.64)
2. 갭상승≥+3% 공매도: +1013%
3. 전일급등 익일 장중 페이딩: +288%
4. **당일 급등 상위20 → 오버나잇 보유(롱)**: +109% (Sharpe 2.34, 공매도 불필요)
5. 52주 신고가 오버나잇: +85%
6~7. 5일/20일 모멘텀 오버나잇: +68~74%
8. 전종목 오버나잇: −10% (naive overnight는 비용에 죽음)
9~16. **모든 약세 매수류**(급락·신저가·손실주): −22~−93%
- ⚠️ "≤−10% 급락 매수"의 1회 +2.45%는 **16일·47거래의 하루(2026-06-08, 30거래)에 좌우된 신기루** — 포트폴리오로는 −34%.

### (12) 국면 분할 (횡보 −4% vs 강세 +230%)
- **모멘텀-오버나잇(급등주·신고가)은 강세장 전용** → 횡보장에선 −11~−28%.
- **횡보장에 플러스였던 단일 기법은 갭상승 페이딩(숏)뿐**(+40%, Sharpe 0.9).

### (13) 페어 트레이딩: 삼성전자 vs SK하이닉스
- **−17%(손실).** 시장중립(베타 +0.05)은 달성했으나, 하이닉스가 HBM/AI로 +1809% vs 삼성 +409% — **공적분 붕괴**(스프레드 추세화). 페어 선택 실패 사례. → `charts/pairs_chart.png`
- 교훈: 페어트레이딩은 **수렴 강제되는 쌍(보통주-우선주 등)** 이어야.

### (14) BNF(고테가와 다카시) 이격도 역추세 — 국면별
- 그의 규칙(25일선 −20% 이상 과대낙폭 매수 → 평균선 복귀 매도, 스윙)을 코스피200에 적용:
  - **횡보장: +4.6%/회, 승률 69%** (최강)
  - 강세장: +1.8%/회 (양호, 모멘텀엔 밀림)
- 우리 "급락 매수"가 졌던 이유와 정반대로 이긴 이유: **①극단 괴리만 ②스윙 보유(수일) ③저회전** → 두꺼운 1회수익이 비용을 압도. → `charts/bnf_chart.png`

### (15) RSI(14) + 볼린저밴드 평균회귀 (`scripts/rsi_bb.py`)
- 규칙: 종가가 볼린저 하단(20,2σ) 이탈 + RSI 과매도 → 매수, 중심선(SMA20) 복귀 매도(15일/−15% 손절).
- **1회 거래 엣지**: 횡보장 RSI<25 시 **+3.81%/회·승률 71%**, RSI<30 +2.87%·68%. 강세장도 +0.6~1.7%로 양(+). **국면 불문 플러스(견고)**, 횡보장 최강. → `charts/rsibb_chart.png`
- **실제 포트폴리오**(동시 10종목·균등·0.20%): 전체 CAGR 5.4%·Sharpe 0.37, 횡보 +9.7%·강세 +5.9% — *모든 국면 양(+)이나 수수함*. 1회수익↔포트 격차는 **자본 가동률**(슬롯 미충족) 탓.
- 판정: 평균회귀 계열(BNF·그레이엄 역발상)과 동일 결론 — **유효하고 횡보장 적합하나 고수익 비법은 아님**.

## 3. 통합 결론 — 한 줄 원리

> **"강세는 밤에 사고(오버나잇 모멘텀), 강세는 낮에 판다(장중 페이딩). 약세는 극단·스윙으로만 산다."**

- **오버나잇 = 모멘텀**: 급등주/신고가는 종가에 사서 다음날 시가에 팔면 수익(강세장 한정).
- **장중 = 반전**: 같은 강세주를 장중 보유하면 되돌림 → 시가 공매도가 강함.
- **약세 매수(역추세)**: 평범한 급락은 더 빠짐. **극단 괴리(−20%)+스윙 보유**(BNF식)만 비용을 이기고, **횡보장에서 최강**.
- **비용/회전이 모든 것을 결정**: 고회전 단타는 gross 엣지가 있어도 비용(2026 거래세 0.20%)에 죽음. 저회전 스윙이 구조적으로 유리.

## 6. 재현 방법
```bash
pip install pykrx   # (선택) 또는 표준 라이브러리만으로 동작
# 1) 데이터 수집 (Yahoo Finance, /tmp/yh = 일봉 3년, /tmp/yh5 = 5분봉 60일)
python3 scripts/fetch.py      # 일봉
python3 scripts/fetch5.py     # 5분봉
# 2) 분석 실행 (예시)
python3 scripts/backtest.py   # 변동성 돌파(일봉)
python3 scripts/battery.py    # 13개 기법 통합 순위
python3 scripts/bnf.py        # BNF 이격도 역추세 국면별
python3 scripts/pairs.py      # 삼성-하이닉스 페어
```
> ⚠️ 스크립트는 데이터 경로를 `/tmp/yh`, `/tmp/yh5`, `/tmp/kospi200.csv`로 가정합니다. 로컬에서는 `research/kospi200.csv`를 `/tmp/`로 복사하거나 스크립트 상단 경로를 수정하세요. 오늘 날짜·Yahoo 데이터에 따라 수치는 달라질 수 있습니다.
